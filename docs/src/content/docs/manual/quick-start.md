---
title: Quick start
description: Connect the SmallTV to WiFi and configure its first screen.
---

1. Power the device and join `SmallTV-Setup`.
2. Open `http://192.168.4.1`.
3. In **WiFi**, save a 2.4 GHz network.
4. After reboot, open the shown IP address or `http://<hostname>.local`.
5. In **Radar**, select both an oblast and district, then save settings.

The Radar screen needs only internet access. Usage metrics need the companion program on your computer; Home Assistant screens need MQTT configured in their tab.

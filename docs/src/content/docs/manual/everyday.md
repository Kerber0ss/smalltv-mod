---
title: Everyday use
description: Use and configure the remaining SmallTV screens.
---

Open the device's IP address or `http://<hostname>.local` to change settings.

- **Radar** shows the selected district’s air-alert status and its drone and missile counts.
- **Usage metrics** displays Claude and Codex data from your local companion client.
- **Home Assistant** receives configured MQTT draw-list screens.
- **Notifications** temporarily overlay the active screen, then return to it.

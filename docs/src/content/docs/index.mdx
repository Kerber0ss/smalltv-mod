The GeekMagic SmallTV is a 1.54-inch ESP8266 cube. This firmware is configured from its built-in web UI and updates over WiFi.

## Screens

<CardGrid>
  <Card title="Air-alert Radar" icon="rocket">
    Regional alert level, selected district or city, and current drone and missile counts from radar.syslog.pp.ua.
  </Card>
  <Card title="Usage meter for Claude and Codex" icon="seti:crystal">
    Usage bars and reset countdowns, received over WiFi from a local PC client.
  </Card>
  <Card title="Home Assistant and notifications" icon="seti:default">
    MQTT draw-list screens and temporary notification overlays.
  </Card>
</CardGrid>
